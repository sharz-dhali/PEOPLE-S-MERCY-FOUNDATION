# People's Mercy Foundation

Public website for People's Mercy Foundation, a charity and community-based
organisation in Nyendo, Masaka, Uganda. The foundation works to improve
people's lives through its community programmes.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
